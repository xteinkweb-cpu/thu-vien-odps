📚 Up sách lên thư viện

Cách lấy mã truy cập (làm 1 lần)
  1. GitHub → bấm ảnh đại diện → Settings → cuối menu trái chọn Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Đặt tên tùy ý, chọn thời hạn dài nhất. Repository access: Only select repositories → chọn repo thư viện.
  4. Permissions → Repository permissions: đặt Contents và Actions đều là Read and write.
  5. Bấm Generate token, copy mã (bắt đầu bằng github_pat_) và dán vào ô trên.
Mã này như mật khẩu: chỉ lưu trong trình duyệt này, đừng gửi cho ai.
Bấm để chọn sách hoặc kéo thả vào đây
epub, pdf, txt, md, fb2 (mỗi file dưới 2 GB)
